# Game Jam! 웹 뷰어 연결

웹: https://game-jam-web-viewer.vercel.app

PC 홈의 **웹 뷰어**에서 게시할 프로젝트를 선택하고 연결 코드를 복사한다. 외부 기기에서는 첫 연결 때 코드를 입력한다. 이후 첫 화면에서 프로젝트를 선택하면 문서·캔버스 뷰어로 이동한다.

로컬 수동 게시본은 PC를 꺼도 마지막 게시 내용이 보인다. 공동 프로젝트와 선택한 로컬 자동 갱신은 PC 연결 프로그램이 저장 내용을 약 15초 간격으로 확인한다. 웹에서도 약 15초 간격으로 갱신하므로 보통 15~30초 뒤 반영된다. 서버·PC·인터넷이 끊기면 마지막 게시본과 게시 시각이 표시된다. 현재 게시본은 프로젝트당 4MB까지이며 초과하면 게시 실패를 표시한다. AI 작업 지시·협업 토큰·로컬 절대 경로는 게시하지 않는다. HTML 결과는 별도 샌드박스에서 네트워크·상위 페이지 접근 없이 표시한다.

홈 폴더 분류, 문서·이미지 카드, 카드 위치·크기·색, 섹션과 HTML 결과를 내보낸다. Markdown의 외부 이미지는 자동으로 요청하지 않는다. 보기 코드는 게시된 모든 프로젝트에 대한 읽기 권한이므로 허용할 사람에게만 전달한다. 다른 기기는 30일 동안 연결된다. 서버의 보기 키 해시를 교체하면 기존 코드·세션을 모두 회수할 수 있다.

## 연결 프로그램

v0.10.7부터 설치된 Game Jam! 앱이 시작하면 저장된 웹 연결 설정을 읽고 즉시 동기화한다. 앱이 실행 중이면 약 15초 간격으로 확인하고, 오류 뒤에도 자동 재시도한다. PC를 재부팅해도 앱을 켜면 다시 연결되므로 별도 웹 바로가기를 실행할 필요가 없다. 앱을 종료하면 자동 확인을 중지하며 웹에서는 마지막 게시본을 계속 읽을 수 있다. 새 프로젝트를 웹에 추가하거나 로컬 자동 갱신을 켜는 것은 홈의 **웹 뷰어**에서 선택한다.

이 PC가 호스팅하는 공동 프로젝트를 관리자로 게시할 때는 협업 서버의 최신 저장본을 직접 읽는다. 임시 터널 주소나 협업 세션이 끊겨도 저장된 AI 생성 Markdown과 HTML 결과를 게시할 수 있다. 다른 PC의 서버에 연결한 프로젝트는 기존 인증된 서버 API를 사용한다.

아래 별도 연결 프로그램은 앱을 닫은 뒤에도 갱신하고 싶을 때 선택적으로 실행한다.

```powershell
npm run web-viewer:build
powershell -NoProfile -ExecutionPolicy Bypass -File tools/web-viewer/start.ps1 -Action Start
```

`Open`은 이 PC에서 웹 뷰어를 열고 자동 연결한다. `CopyCode`는 외부 기기용 코드를 클립보드에 복사한다. `Publish`는 선택된 프로젝트를 다시 게시하고 백그라운드 연결을 시작한다. `Status`는 실행 여부와 게시 결과를 표시한다. `Stop`은 이 도구가 시작한 연결 프로그램만 중지한다. 일반 앱과 협업 서버는 중지하지 않는다. 별도 프로그램은 Windows 시작 프로그램에 등록하지 않는다. PC 재부팅 후에는 Game Jam! 앱을 열어 기본 자동 갱신을 시작하거나, 앱 없이 사용하려면 `Start`를 실행한다.

설정은 `%APPDATA%/Game Canvas/web-viewer.enc`에 Windows `safeStorage`로 암호화해 저장한다. 연결 프로그램은 격리된 프로필에서 기존 앱의 OS 암호화 키만 사용하며 쿠키·세션은 복사하지 않는다. `web-viewer-status.json`에는 게시 시각·성공 수·개인 내용이 없는 실패 메시지만 기록한다. 키는 Git에 넣지 않는다. 별도 웹 저장소의 Vercel 환경에는 `VIEWER_READ_KEY_HASH`, `VIEWER_PUBLISH_KEY_HASH`, 비공개 Blob 저장소 연결이 필요하다. 게시용 원문 키를 브라우저나 공개 환경변수에 넣지 않는다.
