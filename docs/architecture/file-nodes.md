# 캔버스 파일 노드

## 표시와 저장

Markdown과 HTML은 개인 보기 기록이 없으면 접힌 상태로 시작한다. 접힌 크기와 마지막 열림 상태는 runtime의 개인 설정에 프로젝트·파일 ID로 저장한다. 협업에서는 프로젝트와 멤버를 함께 구분한다. 전체 노드에 적용은 현재 프로젝트의 모든 캔버스에서 MD·HTML의 접힌 크기만 변경한다. 공통 모양은 앱 개인 설정이고 색상은 미리보기와 실제 카드가 같은 계산을 사용한다. 기존 파일을 열어도 보기 상태를 frontmatter에 기록하지 않는다.

노드 모양의 MD 제목·본문과 HTML 제목 글씨 크기는 10–32px 범위의 개인 설정이다. 값이 비어 있는 기존 설정은 각 카드의 기본 글꼴 크기를 따른다. 접힌 카드와 펼친 카드가 동일한 설정 값을 공유하고, HTML 게임 프레임은 자체 스타일을 사용한다.

카드를 열면 기존 문서 편집기와 HTML 플레이어를 같은 위치에 표시한다. 검색과 위치 링크의 임시 열림은 개인 기록을 변경하지 않는다. 공동 Markdown의 위치와 펼친 크기는 기존 문서 명령을 사용한다. HTML의 위치·펼친 크기·화면 비율은 기존 개인 창 상태를 사용한다. 접고 펼치는 동작 자체는 iframe을 교체하지 않는다. 캔버스의 기존 콘텐츠 수명 정책은 [캔버스 표시 성능](canvas-performance.md)을 따른다.

접힌 MD와 이미지의 첫 포인터 클릭은 노드를 선택한다. 누르기 직전에 해당 노드만 선택되어 있었으면 다음 클릭으로 MD를 펼치거나 이미지 설명 편집을 시작한다. 드래그·크기 조절·선택 보조 키는 열기를 실행하지 않는다. Enter와 Space는 포커스한 노드를 바로 열고, HTML은 한 번 클릭으로 펼친다.

펼친 파일 카드와 설명 편집 중인 이미지는 일반 파일보다 앞에 표시한다. 같은 층에서는 최근에 조작한 카드를 앞에 배치한다. 이 순서는 현재 캔버스 방문에 한정하며 겹친 항목 메뉴는 화면의 실제 층 순서를 읽는다.

이미지는 캔버스에 투명 배경과 원본 비율로 표시한다. 설명을 편집하는 동안 입력창 위에 캐시된 이미지 미리보기를 표시한다. 작은 이미지는 편집 UI에만 최소 320 × 300px를 확보하고 저장된 이미지 크기는 기존 크기 조절 명령으로 관리한다. 표준 이미지 설명 문서는 기존 Markdown 초안과 편집 잠금을 사용하며 설명 앞뒤의 가져오기 정보를 보존한다. 형식이 다른 문서는 기존 본문 편집기로 연다. 이미지 복사와 탐색기 열기는 기존 컨텍스트 메뉴 명령을 사용한다.

이미지 설명 편집의 헤더와 집중 편집에서 이미지 이름을 입력할 수 있다. Enter·Ctrl+S·완료로 확정하면 기존 Markdown 개명 명령이 노드 제목과 설명 `.md` 파일명을 함께 바꾼다. 같은 문서 ID와 이미지 원본 경로·가져올 때의 이름·바이너리를 유지한다. 참조 갱신, 공동 편집 잠금, 실행 취소·다시 실행은 [문서 개명 정책](decisions/0005-document-file-names.md)을 따른다.

이미지 준비 캐시가 원본 비율을 알려주면 현재 방문의 React Flow 노드에 저장 사각형 안에서 가운데 맞춘 이미지 영역을 투영한다. 이 영역은 선택·손잡이·정렬·연결점의 기준이다. 로드만으로 저장하지 않으며, 이동·정렬·섹션 이동 시 표시 위치를 저장 좌표로 환산한다. 크기 조절은 표시 영역과 저장 사각형을 함께 비례 조정하고 기존 로컬·공동 배치 명령에 기록한다. 설명 카드의 최소 크기는 표시 전용이다.

## 연결과 배치

사운드 노드는 로컬 프로젝트의 Markdown에서 `audio_asset`을 읽고 일반 문서 노드와 같은 배치·복제·섹션 명령을 사용한다. 기본값은 펼침이며 접힘과 음량은 프로젝트·노드별 개인 설정이다. 노드 접힘과 화면 밖 이동 중에는 플레이어를 유지한다. 상위 섹션 접힘은 일시정지하고 캔버스·프로젝트를 떠나면 플레이어를 해제한다. 한 번에 한 노드만 재생한다. 화면에 들어온 파일의 metadata를 읽고 5분 이하는 캔버스의 준비 큐에서 파형을 계산한다. 그 밖에는 재생 위치 슬라이더로 탐색한다. 원본 저장과 세션 범위 재생 URL은 [ADR 0010](decisions/0010-local-audio-assets.md)을 따른다.

3D 노드는 로컬 Markdown의 `model_asset`을 읽는다. 카드의 미리보기를 열면 Three.js와 해당 형식 로더를 불러오고, 활성 뷰어에서만 GPU 컨텍스트를 유지한다. 모델을 닫거나 상위 섹션 또는 캔버스를 떠나면 로드와 렌더링을 종료한다. 메시에 맞춰 카메라를 설정하며 메시가 없는 FBX 리그는 뼈대로 표시한다. 첫 미리보기 뒤의 카드 이미지는 현재 캔버스 방문에서만 유지한다. 저장, Git LFS, 외부 리소스 범위는 [ADR 0011](decisions/0011-local-model-viewer.md)을 따른다.

3D 뷰어를 열면 드래그로 회전한다. Pan 토글을 켜면 드래그로 카메라 시점을 옮기며, 두 모드 모두 휠 확대·축소와 격자 표시를 제공한다. 시점 초기화는 모델을 기준으로 카메라와 회전 중심을 재배치한다.

Follow Camera는 뷰어를 열 때 꺼져 있다. 켜면 현재 클립의 루트 또는 골반 이동을 카메라와 회전 중심에 같은 양만큼 적용해 각도·확대·Pan을 유지한다. 지원하는 위치 트랙이 없는 클립은 시점을 유지한다. 탐색과 반복에도 같은 위치 보정을 적용하며, 시점 초기화는 추적 중인 포즈를 기준으로 기본 구도를 복원한다.

참조는 문서 링크 인덱스에서 열거한다. 제작 입력은 현재 검증된 HTML 제작 기록에서 가져온다. 현재 캔버스의 보이는 양 끝점에만 선을 그린다. 위치 계산에는 React Flow의 표시 영역을 사용한다. 호버, 키 상태와 카메라 갱신은 본문 렌더링 및 플레이어와 분리한다. `G`를 놓거나 창 포커스를 잃으면 임시 전체 표시를 해제한다. `Shift+G`는 열린 앱의 캔버스별로 표시 방식을 전환한다.

AI 요청은 선택적인 접힌 기본 크기를 캡처한다. 기존 작업 명세에 `node_placement`를 저장하고 로컬과 서버가 결과 반영 시 같은 계산을 사용한다. 로컬은 기존 개인 HTML 창 위치를 읽는다. 협업 서버는 확정 직전의 공동 스냅샷만 사용하므로 개인 설정에 따라 일부 카드가 겹칠 수 있다. 힌트가 없는 이전 작업은 기존 배치를 유지한다. 기존 결과를 갱신할 때 위치·크기와 HTML의 배치 식별자를 유지한다. 수동 정렬은 기존 문서 배치 명령과 개인 HTML 창 저장을 각각 사용한다. 일부만 성공하면 저장된 배치를 다시 불러온다.

## 검증

- `tests/file-nodes.test.mjs`는 크기·색상·이미지 설명 범위·선 경로·결과 배치를 확인한다.
- `tests/audio-assets.test.mjs`는 사운드 원본 복사, 중복 참조, 마지막 노드 삭제·복원, 형식 검사와 Git LFS 포인터 보존을 확인한다.
- `tests/model-assets.test.mjs`는 모델 원본 보존, 중복 참조, 복구, 형식별 한도와 Git LFS 포인터를 확인한다.
- `node tests/presentation-actions-packaged.mjs --file-nodes`는 Windows 패키지의 노드 조작과 재시작 복원을 확인한다. `--image-names`는 로컬·공동 이미지 이름 변경 뒤 설명 문서의 경로와 참조, 원본 이미지 보존을 검사한다.
- `node tests/model-viewer-packaged.mjs`는 이동 애니메이션의 탐색·반복 중 카메라 추적과 Pan·확대·초기화를 확인한다.
- 기존 위치 링크·자동 저장·카메라·선택 UI 검사로 카드 표시와 편집 경로의 회귀를 확인한다.
