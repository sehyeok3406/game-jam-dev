# 캔버스 파일 노드

## 표시와 저장

Markdown과 HTML은 개인 보기 기록이 없으면 접힌 상태로 시작한다. 접힌 크기와 마지막 열림 상태는 runtime의 개인 설정에 프로젝트·파일 ID로 저장한다. 협업에서는 프로젝트와 멤버를 함께 구분한다. 전체 노드에 적용은 현재 프로젝트의 모든 캔버스에서 MD·HTML의 접힌 크기만 변경한다. 공통 모양은 앱 개인 설정이고 색상은 미리보기와 실제 카드가 같은 계산을 사용한다. 기존 파일을 열어도 보기 상태를 frontmatter에 기록하지 않는다.

카드를 열면 기존 문서 편집기와 HTML 플레이어를 같은 위치에 표시한다. 검색과 위치 링크의 임시 열림은 개인 기록을 변경하지 않는다. 공동 Markdown의 위치와 펼친 크기는 기존 문서 명령을 사용한다. HTML의 위치·펼친 크기·화면 비율은 기존 개인 창 상태를 사용한다. 접고 펼치는 동작 자체는 iframe을 교체하지 않는다. 캔버스의 기존 콘텐츠 수명 정책은 [캔버스 표시 성능](canvas-performance.md)을 따른다.

이미지는 캔버스에서 원본 비율로 표시한다. 표준 이미지 설명 문서는 기존 Markdown 초안과 편집 잠금을 사용하며 설명 앞뒤의 가져오기 정보를 보존한다. 형식이 다른 문서는 기존 본문 편집기로 연다. 이미지 복사와 탐색기 열기는 기존 컨텍스트 메뉴 명령을 사용한다.

## 연결과 배치

참조는 문서 링크 인덱스에서 열거한다. 제작 입력은 현재 검증된 HTML 제작 기록에서 가져온다. 현재 캔버스의 보이는 양 끝점에만 선을 그린다. 위치 계산에는 React Flow의 표시 영역을 사용한다. 호버, 키 상태와 카메라 갱신은 본문 렌더링 및 플레이어와 분리한다. `G`를 놓거나 창 포커스를 잃으면 임시 전체 표시를 해제한다. `Shift+G`는 열린 앱의 캔버스별로 표시 방식을 전환한다.

AI 요청은 선택적인 접힌 기본 크기를 캡처한다. 기존 작업 명세에 `node_placement`를 저장하고 로컬과 서버가 결과 반영 시 같은 계산을 사용한다. 로컬은 기존 개인 HTML 창 위치를 읽는다. 협업 서버는 확정 직전의 공동 스냅샷만 사용하므로 개인 설정에 따라 일부 카드가 겹칠 수 있다. 힌트가 없는 이전 작업은 기존 배치를 유지한다. 기존 결과를 갱신할 때 위치·크기와 HTML의 배치 식별자를 유지한다. 수동 정렬은 기존 문서 배치 명령과 개인 HTML 창 저장을 각각 사용한다. 일부만 성공하면 저장된 배치를 다시 불러온다.
