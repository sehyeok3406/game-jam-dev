# 보존 동작과 검증 연결

현재 동작을 고정하는 회귀 목록이다. 명령이 존재한다는 사실은 통과를 뜻하지 않는다. 실행 결과는 실행 계획서 작업 기록을 확인한다.

| 보존할 동작                                        | 검사                                                                                                                                             | 데이터/환경                                                                |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 계층 의존 방향·UI runtime 사용·기존 예외 증가 방지 | `npm run test:architecture`, `npm run typecheck:contracts`, `npm run typecheck:core`                                                             | 현재 소스 정적 검사·격리된 검사기 fixture; 간접 의존·업무 동작 검증과 구분 |
| 로컬 저장, 외부 수정 충돌, 재시작 복구             | `npm test`, `npm run test:integration`                                                                                                           | 임시 로컬 프로젝트·mock IPC                                                |
| 공동 문서 저장·잠금·SSE·오프라인·재전송            | `npm test`, `npm run test:autosave:ui`                                                                                                           | 임시 서버·임의 포트·합성 문서                                              |
| 제목/본문/소스 편집의 포커스·선택·연속 입력        | `npm run test:autosave:ui`                                                                                                                       | 격리 Electron 프로필                                                       |
| Markdown 링크·IME 관련 편집                        | `npm test`, `npm run test:document-links:ui`                                                                                                     | 합성 링크·조합 이벤트; 실제 OS IME 입력과 구분                             |
| 실행 환경 주입·IPC와 reducer 반환 계약             | `npm run test:runtime-contracts`, `npm run typecheck:contracts`                                                                                  | 전역 bridge 없이 전달한 어댑터·임시 서버                                   |

| 프로젝트 휴지통·복원·영구 삭제                     | `npm test`, `npm run test:integration`                                                                                                           | 임시 디렉터리·인공 lifecycle                                               |
| 그림·게임 UI·칸반                                  | `npm test`, `test:drawings:ui`, `test:game-ui:ui`                                                                                                | 합성 캔버스·격리 프로필                                                    |

R03의 늦은 완료/같은 경로 재개는 `test:project-session`, R06의 실행·반영 실패/예약/승인/수명 경계는 `ai-executor`, `ai-run-service`, `ai-queue-service`, `approval-service`, `desktop-bootstrap`, `ai-run-coordinator` 단위 검사와 production mock IPC 검사로 연결했다. R04의 26개 명령 대응 검토와 R08~R10의 스키마·백업·Linux 번들 검사는 후속이다. 기존 테스트로 아직 구현하지 않은 경계의 완료를 주장하지 않는다.

다중 이동: `node tests/run-drag-performance-ui.mjs`는 20/100/300개 실제 포인터 이동의 본문 렌더·이동 중 무저장·드롭 배치를 확인한다. `node tests/drag-performance-packaged.mjs`는 최종 패키지의 파일 좌표·본문/metadata·Undo/Redo·재시작을 확인한다. `workspace-commands.test.mjs`는 HTML 배치의 부분 실패와 오래된 응답을 검사한다.
