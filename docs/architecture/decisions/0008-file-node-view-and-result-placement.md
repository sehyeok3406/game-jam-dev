# ADR 0008 파일 노드 개인 보기와 결과 배치

- 날짜 2026-11-06
- 상태 채택

공동 프로젝트에서 각자 원하는 크기로 문서를 접고 펼쳐도 공동 좌표와 편집 내용이 바뀌지 않아야 한다. 생성 결과는 같은 자료를 기준으로 일정하게 배치해야 하며, 실행 요청과 결과 반영 사이에 다른 작업이 공간을 사용할 수 있다.

기본 모양과 파일별 접힘·접힌 크기를 개인 설정에 저장한다. 공동 문서 위치와 펼친 크기, 개인 HTML 창 배치에는 기존 저장 명령을 사용한다. 접힘을 공유 frontmatter에 저장하면 보기 조작이 공동 편집과 히스토리에 섞인다. 접힘을 메모리에만 두면 앱 재시작 요구를 충족하지 못한다.

AI 작업에는 선택적인 너비·높이만 보존하고, 결과 반영 시 기존 로컬·서버 경로가 현재 자료를 읽어 공통 배치 계산을 수행한다. 요청 시 좌표 전체를 예약하면 결과를 쓰기 전에 발생한 배치 변경과 충돌한다. 구버전 요청은 기존 배치를 사용한다. 협업 서버는 개인 HTML 창과 스타일을 읽지 않으므로 개인 화면의 겹침까지 제어할 수 없다.

[파일 노드 설계](../file-nodes.md)에 책임과 검증 경로를 기록한다. 공동 사용자에게 같은 개인 화면을 제공하거나 여러 기기 간 보기 설정을 동기화할 때 이 경계를 다시 검토한다.
