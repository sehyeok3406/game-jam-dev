# ADR 0011 로컬 3D 모델 노드와 뷰어

- 날짜 2026-11-12
- 상태 채택

## 문제와 제약

파일을 캔버스에 배치하고 원본을 보존하면서 모델과 내장 애니메이션을 확인한다. 파일 선택·드롭, Git LFS 공유, 섹션·복사·복구 경로는 사운드와 같다.

## 결정

- `model_asset`은 `assets/models/<SHA-256>.<ext>` 경로, 원래 이름, 크기를 가진다. filesystem repository는 사운드의 원본 저장·실행 취소 경로를 모델로 확장한다. 로컬 객체는 종류별로 유지하고 앱 내 공동 프로젝트의 검증은 로컬 미디어 노드를 거절한다.
- 세션 범위의 미디어 프로토콜을 사운드와 모델이 공유한다. 뷰어는 필요한 로더만 지연 로드하고 닫을 때 렌더러와 모델 자원을 해제한다. 내장 리소스만 모델 로더에 허용하며 외부 텍스처가 연결된 FBX는 기본 재질로 표시한다.
- GLB·FBX·OBJ는 50 MiB, Blender 작업 원본은 256 MiB까지 보관한다. BLEND 열기는 현재 세션의 검증된 프로젝트 경로를 OS 파일 연결에 넘긴다. 홈의 GitHub 공유 안내에서 저장소 설정 예제를 복사할 수 있다.

## 대안과 영향

캔버스 카드마다 WebGL을 실행하면 모델 파일을 일찍 읽고 GPU 컨텍스트 수가 노드 수에 비례한다. 카드에서 여는 단일 뷰어를 사용해 읽기와 렌더링을 사용자가 보는 모델에 한정한다. 외부 모델 리소스 묶음이나 추가 압축 디코더가 필요한 형식을 지원할 때 저장·검증 범위를 재검토한다.

## 검증

`tests/model-assets.test.mjs`로 가져오기·원본 복원·공유 제약을 검사한다. Windows 패키지에서 첨부 GLB·FBX의 실제 표시와 애니메이션 조작, OBJ 및 Blender 원본 동작을 확인한다.
