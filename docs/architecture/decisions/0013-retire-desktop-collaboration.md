# ADR 0013 · 데스크톱 공유 종료와 명시적 원본 정리

2026-11-14 · 채택

## 결정

Windows 데스크톱은 로컬 프로젝트를 열고 AI 제작, 저장, 기록 복원, 미리보기와 HTML 내보내기에 기존 경로를 사용한다. 홈과 preload에서 해당 공유 기능을 숨기고 메인 프로세스에서 공유 세션, 모드 전환과 위치 링크를 차단한다. 시작 과정은 이전 등록과 캐시를 디스크에서 확인하고 서버 확정이 기록된 로컬 전환만 완료한다. 공동 생성 저널은 보존한다. 게임의 기존 파일과 로컬 미리보기는 유지한다. 새 AI 작업은 온라인 모듈 없이 준비한다. 자동 웹 출판은 로컬 항목에만 실행하며 앱 업데이트 경로는 기존 흐름을 사용한다.

공유 카드는 PC 사본과 마지막으로 확인한 서버 상태를 표시한다. 사본은 기존 7일 휴지통을 이용한다. 서버 관리 등록과 자격은 OS 암호화 저장소에 남겨 PC 사본을 영구 삭제한 뒤에도 관리할 수 있다. 홈과 휴지통은 선택된 프로젝트의 서버 상태만 조회한다. 이름과 영향 확인이 필요한 삭제는 서버가 보고한 이름과 상태를 사용한다.

외부 서버 원본 정리는 저장된 주소·자격과 기존 관리자 요청을 사용한다. 내장 정리는 프로젝트 ID에 고정된 임시 loopback listener를 기존 SQLite writer·권한·수명 서비스에 연결한다. 서버가 현재 권한을 검증한다. 선택 대상에 대한 네 가지 휴지통 요청을 처리하고 종료 후 writer를 해제한다. 백그라운드 협업, 서버 전체 만료 정리, 예약 백업은 일반 데스크톱이나 임시 정리 경로에서 실행하지 않는다.

## 대안과 호환

UI만 숨기면 저장 세션과 IPC에서 일반 협업을 시작할 수 있다. 기존 공유 앱과 서버 코드를 함께 제거하면 암호화된 등록과 원본 정리 경로도 사라진다. 데스크톱 진입 경로를 닫고 기존 서버 서비스와 보관 형식을 사용하면 원본의 권한과 단계별 저장을 유지할 수 있다.

복원과 영구 삭제는 예상 버전을 현재 상태와 원자적으로 비교할 수 있는 서버에서 실행한다. 이전 외부 서버에서도 상태 조회와 휴지통 이동을 이용할 수 있다. 복원과 영구 삭제를 하려면 서버 업데이트가 필요하다. 보관기간이 지난 내장 항목은 사용자가 선택하여 영구 삭제할 수 있다. 외부 서버 자체의 운영과 정기 만료 정책은 그 서버가 소유한다.

## 검증

`tests/local-first-packaged.mjs`는 격리된 Windows 프로필로 콜드 스타트, 공유 거부, PC 사본 보관·복원·삭제, 명시적 내장·외부 서버 정리, 오류 및 writer 해제를 검사한다. `tests/game-build-execution-packaged.mjs`는 모의 AI CLI와 실제 빌더 경로를 사용하는 패키지 회귀 검사다. 여기에 설계와 검증 경로를 기록하며 실행 증거는 해당 검증 로그에서 확인한다.
