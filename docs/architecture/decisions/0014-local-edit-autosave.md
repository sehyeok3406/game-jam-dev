# ADR 0014 · 로컬 편집 원본 저장과 세션 작업 기록

2026-11-22 · 채택

## 문제

펜을 놓을 때마다 그림 원본을 교체하고 전후 파일을 기록하면 짧은 획을 연달아 그릴 때 디스크 작업이 누적된다. Markdown과 캔버스 텍스트도 편집 중 수시로 원본을 쓰고 있었다. 사용자는 원본 저장 빈도를 줄이면서 펜·도형·지우기 동작을 개별적으로 되돌리고 싶다.

## 결정

- 열린 로컬 프로젝트 세션이 마지막 편집에서 2분간 유휴이면 Markdown 본문과 그림 파일의 미확정 변경을 기존 mutation 큐에서 함께 저장한다. 펜·도형·지우개와 캔버스 텍스트는 같은 그림 원본 경로를 사용한다. 화면 이동·확대·단순 선택은 타이머를 갱신하지 않는다. `Ctrl+S`, 정상 종료, 프로젝트 전환, AI 시작 및 원본에 의존하는 구조 변경은 즉시 저장 경계를 사용한다.
- 기존 `DocumentSaveQueue`가 Markdown 요청을 문서별 최신 상태로 합친다. 그림은 처음 변경한 파일의 원본과 현재 대기 내용만 보관하며, 화면 조회에 대기 내용을 반영한다. 저장할 때 문서 ID·내용, 그림의 원본 바이트와 세션·AI 파일 잠금을 검사한다. 기존 원자적 파일 반영과 기록 형식을 사용해 실제 변경이 있는 저장 묶음마다 디스크 버전 한 건을 기록한다. 확정 중 접수된 작업은 다음 묶음에 남는다.
- 기존 `EditJournal`은 그림 한 획, 도형 하나, 지우기 한 번의 변경을 각각 기록한다. 바뀐 그림 객체만 전후로 보관하며 메모리에 남기는 작업 항목은 최근 20개다. `Ctrl+Z`와 다시 실행은 이 작업을 현재 캔버스에 적용하고 원본 저장 대기 내용을 갱신한다. 파일에 기록하는 버전은 동일한 시점에 바뀐 여러 항목을 담는다. 이전 디스크 기록의 조회·복원에는 기존 경로를 사용한다.
- 입력이 아직 완료되지 않은 펜·도형과 텍스트는 2단계 복구 형식을 사용한다. 확정된 대기 그림은 기존 초안 저장소의 프로젝트별 레코드로, Markdown 본문은 기존 문서 큐의 복구 레코드로 체크포인트한다. 주기는 30초이며 이전 초안이 포함하던 진행 중 작업을 넘겨받을 때에는 해당 그림을 먼저 보관한다. 버린 초안은 저장소에도 반영한다. 프로젝트를 다시 열면 완료된 그림의 보관 초안을 확인하고 복구할 수 있다.

## 검토한 대안과 영향

편집마다 원본과 히스토리를 기록하면 종료 시 일반 복구가 단순해진다. 그 방식에서는 연달아 그리는 동안에도 모든 획이 파일 교체와 버전 기록을 만든다. 문서별 타이머를 사용하면 구현은 단순하지만 캔버스에서 작업 중에 같은 프로젝트의 원본 저장이 계속 시작된다. 프로젝트 단위로 유휴 시간을 재고 복구를 따로 기록하면 편집을 이어가는 동안 반복 원본 쓰기를 줄일 수 있다.

공동 저장 계약과 기존 디스크 히스토리 형식을 계속 사용한다. 원본 쓰기 직전에 최신 초안을 보관하고 히스토리의 전후 스냅샷과 로컬 복구 표식을 디스크에 남긴다. 저장 중 강제 종료 후 프로젝트를 열면 모두 반영된 묶음은 같은 히스토리 ID로 확정한다. 일부만 반영된 묶음은 기록한 저장본과 바이트가 일치하는 파일만 되돌린다. 외부 파일과 최신 초안은 계속 보관하고, 충돌한 문서는 사용자가 최신 원본을 확인한 뒤 다시 저장할 수 있다.

파일 교체 직전에 원래 내용을 다시 검사하며 Windows 공유 오류로 재시도할 때에도 같은 검사를 한다. 다른 프로세스가 마지막 비교와 교체 사이에 같은 파일을 쓰는 극히 짧은 구간에는 파일 시스템 차원의 공동 잠금이 없다. 메인 프로세스가 쓰는 일괄 그림 초안에는 편집기 초안의 200만 자 한도를 적용하지 않는다. 일반 IPC 초안과 이전 형식은 기존 규칙을 따른다. 저장과 폐기 요청은 열린 세션에 고정한다.

## 검증

`tests/local-edit-batch.test.mjs`의 고정 시계로 유휴 초기화, 여러 파일의 한 버전 기록, 저장 도중 큐에 들어온 편집과 실패 재시도를 검증한다. `tests/local-edit-publication.test.mjs`는 전부 반영된 뒤의 복구와 교체 직전 외부 변경을 다룬다. `tests/local-save-recovery-packaged.mjs`는 Windows 패키지의 첫 원본 교체 직후 강제 종료, 외부 파일과 최신 초안 보존, 같은 경로 재열기 및 재시도 시의 기록 한 건을 확인한다.
