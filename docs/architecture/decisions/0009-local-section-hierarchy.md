# 0009 · 로컬 캔버스의 중첩 섹션

- 날짜: 2026-11-12
- 상태: 채택

섹션을 폴더처럼 정리하면서 프로젝트의 Markdown·에셋·결과물 경로를 유지한다. 하위 섹션 Markdown의 `parent_section_id` 하나로 상하 관계를 저장한다. 상위 문서와 하위 문서 양쪽에 관계를 기록하는 방식은 Git 병합 시 두 값을 맞춰야 한다. 실제 폴더 이동 방식은 파일 링크와 Git 변경 범위까지 바꾸므로 채택하지 않았다.

계약에는 선택적 상위 ID를 노출하고, core의 트리 계산을 화면·명령·복사가 공유한다. 기존 로컬 저장 큐와 Markdown 변경 이력을 사용한다. 기존 프로젝트에서 상위 ID가 없는 섹션은 최상위로 읽는다. 유효하지 않은 상위 연결은 읽기 시에만 제외하고 재배치할 때 갱신한다.

공동 프로젝트는 평면 섹션 계약을 사용한다. 공유 전송과 복사에서 로컬 중첩 관계를 검사한다. 공동 편집에서 중첩 섹션을 지원할 때는 서버 capability, 권한, 구버전 동기화와 실행 취소를 함께 설계한다.

기존 및 중첩 섹션의 화면과 저장 검증은 [섹션 명령 안내](../section-actions.md)를 따른다.
