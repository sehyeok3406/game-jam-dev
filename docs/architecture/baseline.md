## 안전한 재현

검사는 합성 문서, 임시 서버, 임의 포트 또는 `out/` 안 격리 테스트 프로필을 사용한다. 실제 프로젝트, 운영 서버/터널, AI 계정, Render 자원은 사용하지 않는다. mock CLI 결과는 실제 공급자 로그인/실행 검증으로 보고하지 않는다.

타입 검사·기본 테스트·린트는 병렬 실행할 수 있다. Vite UI 서버들은 같은 의존성 최적화 캐시를 사용할 수 있어 순차 실행한다. 네이티브 앱 포커스/클립보드 검사도 순차 실행한다. `test:ui-debug`는 자체 `out/ui-debug-build`를 생성한다. Forge 패키징 중에는 같은 `.vite` 출력에 다른 빌드를 실행하지 않는다.

새 실패는 이 문서에 소급해 기존 실패로 넣지 않는다. 이후 실행 결과는 실행 계획서의 작업 기록에 계속 남긴다.
