# v0.46.1 배포 기록

2026-11-06 [v0.46.1 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.46.1)를 게시했다. 태그는 `main`에 푸시한 소스 커밋 `2776b958c796927ed875ed944c167e9a3bf447a3`를 가리킨다. [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/42224892059)의 타입·린트·Windows 자동 테스트·Linux 서버 검사가 통과했다. 로컬 자동 테스트는 1,225개 통과, 1개 건너뜀이다.

최종 Windows x64 패키지에서 펼친 카드의 앞뒤 순서와 크기 조절, 가로·세로 이미지의 투명 배경, 설명 입력창 위 미리보기, 저장된 이미지 크기와 재시작 후 초안 복원을 확인했다. 업데이트 화면 검사는 처음에 펼친 카드만 찾는 기존 테스트 조건에서 멈췄다. 격리된 검증 사본에서 메모를 클릭해 펼친 뒤 기존 검사를 진행했고, 업데이트 알림과 편집 중 재시작 보호를 확인했다.

`make --from-package`로 검증한 빌드에서 설치 파일을 만들었다. 빌드 리소스 2,046개의 크기와 SHA-256이 설치용 nupkg 내부와 일치했다. 내장 서버 번들의 SHA-256은 `d55d9d4776cfc5e72c0029b2c2f1a2e9e4df7afd05dd88446e1883d9f87cc86f`이며, 동일한 별도 번들의 실행과 경계 검사도 통과했다.
