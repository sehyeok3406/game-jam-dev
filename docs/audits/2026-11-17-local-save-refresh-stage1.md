# 로컬 저장과 화면 갱신 1단계 검증

2026-11-17 · 완료 · 기준 커밋 `54b6567`에 1단계 변경을 적용한 Windows x64 로컬 패키지

## 확인한 동작

- 일반 Markdown을 앱에서 저장하면 기존 저장 응답으로 화면을 갱신한다. 히스토리 기록이 성공한 뒤 실제로 파일에 쓴 바이트를 기준으로 같은 세션의 파일 감시 알림을 대조한다. 바이트가 일치하면 화면에서 해당 파일을 추가로 읽지 않는다. 다른 내용이 감지되면 외부 변경 갱신을 예약한다.
- 외부에서 기존 일반 Markdown을 수정하면 해당 경로의 문서만 읽는다. 문서 ID·종류·소속 캔버스·HTML 연결이 달라졌거나 기존 문서를 찾기 어려우면 전체 갱신으로 전환한다. 파일 추가·삭제, 프로젝트 이름에 영향이 있을 수 있는 `project.md`의 외부 변경, 자료·작업 상태가 함께 바뀌는 AI 결과 반영은 전체 갱신 경로를 사용한다. [부분 갱신 설계](../architecture/canvas-performance.md)

## 회귀 검증

- Windows 패키지에서 외부 메모 수정 후 다른 메모 편집기의 DOM·포커스와 실행 중인 HTML iframe을 확인했다. 편집 중인 메모와 외부 변경이 충돌하면 디스크에 외부 내용, 편집기에 로컬 초안을 보존했다. 같은 경로의 문서 ID가 바뀐 경우 새 문서가 화면에 나타났다. [패키지 검사](../../tests/local-document-refresh-packaged.mjs)
- 같은 패키지의 그림·지우개 되돌리기, 문서·섹션 수정·삭제·재시작 검사가 통과했다. TypeScript 타입 검사와 자동 테스트가 통과했다. 자동 테스트는 1,256개 통과, 선택 검사 1개 건너뜀이다. 자동 테스트에 아키텍처 검사가 포함됐다.
