# v0.53.1 배포 기록

2026-11-15 Windows x64 정식 릴리스를 게시했다. 배포 커밋과 `v0.53.1` 태그는 `183ef64a16bf74eba359869f91168d5e0f693b8c`를 가리킨다. 타입·계약·코어·아키텍처 검사, 추적 파일의 린트와 Windows·Linux CI가 통과했다. 로컬 자동 테스트는 1,249개 통과, 선택 검사 1개 건너뜀이었다. 내장 서버 번들의 경계·실행 검사도 통과했다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.53.1) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43687235558)

실제 Windows 패키지에서 `Project-PP_gamejam`의 격리 사본을 열었다. HTML·MD·이미지 노드를 선택 해제할 때 저장·목록 요청이 없었다. 이동 시 HTML은 창 설정을 저장했고, MD·이미지는 이동한 문서의 배치를 읽었다. 전체 HTML 및 문서 목록을 다시 요청하지 않았고, 세 노드의 화면 이동량과 저장된 이동량이 일치했다. 재시작 후에도 새 위치가 보존됐으며 외부에서 수정한 MD 본문도 캔버스에 반영됐다.

별도 전체화면 재생 UI 검사는 수정 전후 동일한 Electron 스크립트 실행 오류로 실패했다. 배포 소스는 전체 테스트와 변경 기능의 실제 패키지 검증을 통과했다.

검증한 패키지에 `make --from-package`를 적용했다. 배포 소스의 지문과 패키지 리소스 지문이 빌드·검증·설치 파일 생성 과정에서 일치했다. nupkg에 포함된 리소스 2,046개의 SHA-256과 크기를 검증한 패키지와 대조했다.

| `game_canvas-0.53.1-full.nupkg` | 239612466 | `629823fd9d157b8ff0e3acc3c42e632cc001aa06d697da0b4866020765c0a1b6` |

GitHub 자산의 SHA-256과 크기는 로컬 파일과 일치하며, 세 파일 모두 인증 없이 HTTP 206으로 접근했다. 공개 `RELEASES` 원문도 일치했다. 이 파일의 패키지 이름과 SHA-1 `3721A0CDF51EE77936BA67EB3C3650767E042A82`, 크기 239612466바이트를 확인했다.

v0.53.0 기준 업데이트 JSON은 새 설치 파일 URL을 반환했다. Windows Squirrel 피드는 첫 요청에서 HTTP 500을 반환했고, 오류 확인 요청에서 HTTP 200으로 응답해 새 nupkg URL과 SHA-1 및 크기가 일치함을 확인했다. 배포 파일 게시·검증과 자동 업데이트 피드 반영을 완료했다. 검증 로그는 `out/release-v0.53.1`에 있다.
