# 로컬 저장 중단과 외부 충돌 검증

2026-11-22 · 4단계 완료 · Windows x64 로컬 패키지

- 원본을 쓰기 직전에 최신 초안과 히스토리 전후 파일을 보관한다. 재열기에서 모든 원본이 이미 반영된 묶음은 같은 ID로 확정한다. 일부만 반영된 묶음은 앱이 쓴 바이트가 남은 파일만 원복한다. 교체 전에 외부 변경을 확인하고, 저장과 폐기는 요청을 시작한 세션에 고정한다. [ADR 0014](../architecture/decisions/0014-local-edit-autosave.md)
- 동일 Windows 패키지 번들을 첫 파일 교체 직후 멈춰 강제 종료했다. 그 사이 외부에서 수정한 Markdown을 보존했고, 재실행한 Windows 실행 파일은 그림 원본만 되돌렸다. 30초를 기다리기 전에 접수한 Markdown·그림 초안이 남아 있었다. 이전 세션의 저장·폐기 요청은 거부됐다. 충돌을 확인한 뒤 다시 저장했고, 두 변경 파일을 포함한 히스토리 한 건만 확정됐다. [패키지 시나리오](../../tests/local-save-recovery-packaged.mjs)
- 타입·계약·아키텍처 검사, 저장·복구 관련 자동 검사 22개, Windows 그림 Undo/Redo 검사를 실행했다. 입력 구간의 읽기·쓰기와 화면 반영 수치는 3단계 계측을 사용했다. 이번 단계는 저장 경계와 복구에 집중했다. [3단계 계측](2026-11-22-local-save-refresh-stage3.md)

외부 편집기와 파일 잠금을 공유하지 않으므로 마지막 비교와 교체 사이의 동시 쓰기를 완전히 직렬화할 수 없다. 검증 범위는 앱 프로세스의 강제 종료다.
