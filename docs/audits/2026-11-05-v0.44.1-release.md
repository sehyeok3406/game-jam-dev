# v0.44.1 배포 기록

2026-11-05 [v0.44.1 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.44.1)를 게시했다. 배포 파일 게시·검증과 자동 업데이트 피드 반영 완료다. 제품 소스·태그는 `6eff75ce86aa6778e402032800fd1bb4375b7fe8`이다. [CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/41972280707)의 타입·린트·Windows 자동 검사·Linux 서버 작업이 모두 통과했다.

홈과 프로젝트 화면의 우측 하단 수동 위치 링크 버튼·붙여넣기 패널을 제거했다. 직접 링크 열기와 위치/문단 링크 복사를 유지하고 오류가 있을 때만 기존 형식의 공통 안내창을 표시한다. 한글 조합 중에는 기존 알림으로 안내한다. 기존 v0.44.0 서버와 호환된다.

변경 범위의 로컬 타입 검사·아키텍처 10개·hook/프로토콜 3개·production renderer 검사를 수행했다. 최종 소스로 한 번 package하고 실제 Windows 실행 파일의 링크 수신/OS 전달·문단·HTML·텍스트·도형/이미지를 확인했다. 동일 결과물의 make --from-package를 사용했으며 2,046개 리소스의 make 전후·nupkg 내부 해시와 크기가 같다. 변경하지 않은 저장·서버 영역의 전체 로컬 검사를 반복하지 않았으며 최종 소스의 전체 자동 검사는 CI에서 확인했다.

제품 입력 671개 지문은 `198c00d0ec3827c8af9ec448987e8877140f3b2abb8eed8601d1683442af62bd`, app.asar SHA-256은 `7c8e5ac4aee91b5f308bf9e323eff40c21e1e2d1210be0eb814151bda9691bad`이다. 초기 지문 뒤 main 체크아웃이 4개 파일의 LF를 CRLF로 바꾼 사실을 정규화 해시로 확인했다. 빌드 후와 make 이후에는 동일한 체크아웃 지문을 사용했다. 소스 의미 변경이나 추가 빌드는 없으며 원래 지문과 차이 증거는 JSON에 보존했다.
