# v0.52.0 배포 기록

2026-11-14 Windows x64 정식 릴리스를 게시했다. 배포 소스는 `b84f8a588f5dd3d7d79c666c9047a07700d6ace9`다. 타입·계약·코어·아키텍처 검사와 Windows·Linux CI를 통과했다. 로컬 자동 테스트는 1,248개 통과, 선택 검사 1개 건너뜀이며 패키지 런타임 검사 15개를 통과했다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.52.0) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43584747983)

최종 Windows 패키지에서 모의 AI CLI로 라이브러리 제안을 작업 기록에서 선택하고, 실제 Three.js를 로컬 새 버전에 추가했으며, 공동 프로젝트에서 삭제한 결과가 서버와 로컬 캐시에 반영되는 것을 확인했다. 실패 시 이전 결과 보존과 기록 복원도 검증했다. 내장 서버와 별도 서버 번들의 SHA-256이 `f999f3688dbc00378b843a579e4729fd34fd472c41604621e9a3bd806b82e4e9`로 일치하고 번들의 실행·부하 검사를 통과했다.
