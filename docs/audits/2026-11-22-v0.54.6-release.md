# v0.54.6 배포 기록

2026-11-22 Windows x64 정식 릴리스를 게시했다. 배포 커밋과 태그는 `9bc8f947bf7d526e0a4209c11d21b1e74d0a028e`를 가리킨다. 타입·계약·코어·아키텍처, 린트, Windows 자동 테스트, Linux 서버·복구 GitHub CI가 통과했다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.54.6) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/44975164795)

배포용 Windows 패키지에서 사각형·펜 획·지우기 실행 취소와 다시 실행 때 문서 전체를 다시 읽지 않는지 확인했다. 저장 도중 강제 종료한 뒤 외부에서 바뀐 원본과 최신 초안이 남고, 재시도 후 히스토리가 한 버전으로 확정되는지 확인했다. 자동 테스트는 1,269개 통과, 선택 검사 1개 건너뜀이다.

v0.54.5 후보의 Windows CI에서는 임시 경로의 대소문자 차이로 테스트가 외부 변경을 주입하지 못했다. 소문자 임시 경로에서 같은 실패를 재현하고, 테스트가 실제 경로를 사용하도록 수정한 뒤 v0.54.6으로 다시 빌드했다. [v0.54.5 후보 CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/44974731290)

검증한 패키지에 `make --from-package`를 적용했다. 빌드를 시작한 Git 트리는 배포 커밋의 트리와 일치한다. 패키지 생성과 설치 파일 생성 후 추적 소스 1329개의 지문은 `199d18de88cd4f1ed7c7b1e0b061567c2b23c24b4d65062a6bbbf04e8d3b34e0`로 일치했다. nupkg 리소스 2046개는 검증한 패키지의 SHA-256과 크기를 유지했다.
