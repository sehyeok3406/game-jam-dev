## 검증 범위

- 최신 원격 v0.42.0 파일명 변경을 합치고 게임 원본/기준 문서 개명 연결을 회귀 검사와 실제 Windows local/shared 패키지에서 확인했습니다. 원격 ADR 0005와 구분해 게임 제작 결정은 ADR 0006으로 정리했습니다.
- Windows CI에서 실제 드러난 TEMP 경로 별칭 문제는 stage 생성부터 realpath를 사용하도록 수정했습니다. 정리 경로 보호를 유지하며 별칭 회귀 검사를 추가한 뒤 CI가 통과했습니다.
- 실제 package의 생성·수정·새 버전·실패·복원·재시작·native 내보내기/재가져오기, 파일명 UI와 source 연결, 동봉 도구 14건과 Node/서버·새 합성 Windows 백업 복원 검사를 통과했습니다. 작성 CLI는 이 배포 검사에서 mock이며 앞선 [7단계](2026-11-03-game-build-stage7.md)의 실제 Codex·브라우저 증거와 구분합니다.
- 설치 파일은 검증한 패키지를 재사용해 생성했고 기존 make 파일을 직접 업로드했습니다. 전체 설치 파일/nupkg를 반복 다운로드하지 않고 GitHub digest·크기·공개 접근을 확인했습니다. RELEASES는 BOM을 포함한 바이트로 비교했습니다.
- 새 아키텍처 예외나 검사 완화는 없습니다. 별도 미커밋 계획서로 인한 작업 폴더 포맷 문제와 달리 커밋된 릴리스 트리 및 CI의 린트/포맷은 통과했습니다.

전체 수치와 공개 검증 응답은 [측정 JSON](2026-11-03-v0.43.0-release-evidence.json), 로컬 결과물·로그는 out/release-v0.43.0 및 out/release-\*.log에 보존했습니다. 기존 설치 앱의 실제 업데이트 설치·사용자 운영 서버 재시작은 이번 릴리스 게시 검증에 포함하지 않습니다.
