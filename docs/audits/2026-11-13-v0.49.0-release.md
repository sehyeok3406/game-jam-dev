# v0.49.0 배포 기록

2026-11-13 [v0.49.0 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.49.0)를 게시했다. 공개 태그는 배포 소스 `65a9886ea769e3755ea32abf0c83a357a507881b`을 가리킨다. 타입·아키텍처·린트·Windows 자동 테스트·Linux 서버 검사가 통과했다. 로컬 자동 테스트는 1,243개 통과, 선택 검사 1개 건너뜀이다. [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43323282530)

최종 Windows x64 패키지에서 로컬·공동 이미지 이름 변경, 로컬 이미지 원본의 휴지통 이동·실행 취소·다시 실행·재시작 후 복원·영구 제거를 확인했다. 복원 후 프로젝트를 다시 연 직후 우클릭 메뉴는 한 번 더 열어서 재삭제를 확인했다. 프로젝트 휴지통의 로컬·공동 복구와 섹션·구성원 삭제 및 복원 회귀도 통과했다. 최초 CI에서 실패한 파일 휴지통 검사는 Windows 단축 경로를 `realpath`로 정규화해 재검증했다.

`make --from-package`로 검증한 패키지에서 설치 파일을 만들었다. Windows 패키지 리소스 2,046개의 SHA-256과 크기가 nupkg 내부와 일치한다. 내장 협업 서버와 별도 서버 번들의 SHA-256 `8b9ffef9025f32746f197714b19b1b447664a5c13c9099d7863afc8e3a15ea41`이 일치하고 서버 번들의 실행 검사가 통과했다.
