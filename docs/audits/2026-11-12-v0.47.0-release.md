# v0.47.0 배포 기록

2026-11-12 [v0.47.0 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.47.0)를 게시했다. 태그와 배포 소스는 `60b4b585b2b8ea8b904c49daf0d613bf4b813dc2`로 일치한다. [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43160315350)의 타입·린트·Windows 자동 테스트·Linux 서버 검사가 통과했다. 로컬 자동 테스트는 1,236개 통과, 공식 Grok CLI 선택 검사 1개 건너뜀이다.

최종 Windows x64 패키지에서 중첩 섹션의 재시작 복원과 편집 기록, MP3·PCM WAV·Ogg Opus 재생과 음량·탐색, 첨부 GLB·FBX의 3D 조작과 애니메이션을 확인했다. OBJ 표시, BLEND의 Blender 열기, Git LFS 포인터 안내·복구, 외부 텍스처 FBX와 압축 GLB 안내, 원본 삭제·실행 취소, 기존 이미지·HTML 노드와 공동 프로젝트의 이미지 배치 회귀를 확인했다.

`make --from-package`로 검증한 패키지에서 설치 파일을 만들었다. 패키지 리소스 2,046개의 SHA-256과 크기가 설치용 nupkg 내부와 일치한다. 내장 서버와 별도 협업 서버 번들의 SHA-256 `3931cea8f7e328299942d399874c439aae426312248b2e71eab4c393fc382fa6`이 일치하고 별도 번들의 실행 검사도 통과했다.
