# v0.50.0 배포 기록

2026-11-13 [v0.50.0 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.50.0)를 게시했다. 공개 태그는 배포 소스 `49034ea5ea2dfbc2f13a10f699ade8be84120743`을 가리킨다. 타입·아키텍처·린트·Windows 자동 테스트·Linux 서버 검사가 통과했다. 로컬 자동 테스트는 1,243개 통과, 선택 검사 1개 건너뜀이다. [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43430222859)

최종 Windows x64 패키지에서 모의 AI CLI로 13,503,714바이트 HTML을 생성해 실제 빌드·초기 실행·저장·이력 복원과 빌드 실패 후 기존 결과 보존을 확인했다. 네이티브 파일 선택·드롭·붙여넣기, 로컬 프로젝트 간 복사와 바이트가 같은 HTML 내보내기도 확인했다. 78,503,721바이트 제작 결과를 저장한 뒤 앱을 재시작해 캔버스에서 실행했다. 별도의 전체화면 입력 검사는 변경 전 코드에서도 같은 오류로 실패했다.

`make --from-package`로 검증한 패키지에서 설치 파일을 만들었다. Windows 패키지 리소스 2,046개의 SHA-256과 크기가 nupkg 내부와 일치한다. 내장 협업 서버와 별도 서버 번들의 SHA-256 `31da24316ea0467bf8be2d452c4faf120f99f942831995e9a371075509fc5580`이 일치하고 서버 번들의 실행 검사가 통과했다.
