# 로컬 원본 저장 3단계 검증

2026-11-22 · Windows x64 로컬 패키지 · 기준 커밋 `54b6567`에 1~3단계 변경 적용

## 저장 정책

마지막 편집 후 2분간 추가 편집이 없으면 열린 프로젝트의 Markdown과 그림 변경을 저장한다. `Ctrl+S`, 프로젝트 전환, 정상 종료, AI 실행 전에는 원본 확정을 기다린다. 변경 파일의 전후를 한 버전으로 기록하고 그림 편집은 최근 20개 작업을 세션에서 개별적으로 되돌릴 수 있다. [ADR 0014](../architecture/decisions/0014-local-edit-autosave.md)

## 같은 입력의 파일 작업 횟수

일반 Markdown 문서 122개, 섹션 1개, HTML 5개 프로젝트에서 기준선 시나리오를 실행했다. 준비 동작과 의도적으로 누른 `Ctrl+S`는 아래 입력 구간 밖에 있다. [0단계 기준선](2026-11-17-local-save-refresh-baseline.md) · [2단계 초안 검증](2026-11-22-local-save-refresh-stage2.md)

| 입력 구간         | 원본 쓰기 · 2단계 → 3단계 | 히스토리 전후 / 항목 쓰기 · 2단계 → 3단계 | 전체 문서·섹션·HTML 목록 조회 |
| ----------------- | ------------------------: | ----------------------------------------: | ----------------------------: |
| 메모 한 건 편집   |                     1 → 0 |                             2 / 1 → 0 / 0 |                             0 |
| 연속 펜 6획       |                     6 → 0 |                            12 / 6 → 0 / 0 |                             0 |
| 펜 한 획 되돌리기 |                     1 → 0 |                             2 / 1 → 0 / 0 |                             0 |

Windows x64 패키지와 같은 Electron 44.5.1의 계측 결과는 `out/local-save-baseline/gamejam-resize-packaged-4knGTI`에 있다. 연속 펜 6획에서 그림 원본 읽기는 36회에서 1회로 줄었다. 화면 반영은 획당 6.9~11.9ms, 마지막 획 되돌리기는 13.6ms로 관측됐다. 원본 교체는 다음 명시적 저장 구간에서 발생했다.

Windows 직접 저장 검사에서 메모 편집과 펜 세 획을 유지하고 마지막 한 획을 되돌린 뒤 `Ctrl+S`를 눌렀다. 확인한 히스토리 항목 한 건에는 메모 파일과 두 획이 남은 그림 파일이 들어 있었다. 저장 직후에도 세 번째 획을 다시 실행했고 획별로 Undo/Redo를 이어갈 수 있었다. 화면에서 세 획이 보일 때 원본에는 두 획이 있었으며, 정상 종료가 남은 획과 종료 직전에 편집한 메모를 원본에 함께 확정했다.

## 검증 범위

- 고정 시계에서 입력이 이어지면 타이머를 다시 세고 2분에 한 번 저장하는 동작을 확인했다. 쓰기 도중 들어온 작업은 다음 큐에 남았고, 히스토리 쓰기 실패는 같은 ID로 재시도했다. 새로 접수한 Markdown은 마지막 내용만 30초 복구 레코드에 남고, 실제 원본·히스토리 확정 후 제거된다. [고정 시계와 재시도 검사](../../tests/local-edit-batch.test.mjs) · [문서 큐 검사](../../tests/document-save-queue.test.mjs)
- 최종 Windows 패키지에서는 확대 후에도 입력 시작 약 120.4초에 첫 자동 저장이 일어났다. 다른 프로젝트로 이동하기 전 메모와 그림 원본을 저장했고 같은 경로를 다시 열 때 앞 세션의 메모리 작업이 나타나지 않았다. 모의 AI CLI가 디스크에서 최신 Markdown을 읽었다. 30초에 보관한 그림을 강제 종료 후 복구했다. 직사각형·펜·지우개 Undo/Redo, 외부 Markdown 충돌, 섹션·휴지통·기존 히스토리 재시작 검사도 통과했다. [패키지 검사](../../tests/local-idle-save-packaged.mjs)
- 통합 타입·계약·core 검사, 변경 파일 린트, `npm test`가 통과했다. 자동 테스트 1,267개가 통과했고 선택 검사 1개를 건너뛰었다. 아키텍처 검사는 `npm test`에 포함된다.
- 기존 Markdown·그림 초안 복구와 사용자가 버린 초안의 재표시 방지를 검증했다. 진행 중인 펜의 첫 초안은 약 30.0초에 관측됐다. Markdown 제목과 연속 입력 중인 캔버스 텍스트의 강제 종료 후 복구도 통과했다. [이전 초안 회귀 검사](../../tests/local-draft-checkpoint-packaged.mjs)
- 원본 일괄 쓰기 중 강제 종료, 아주 큰 그림 초안과 복합 외부 충돌의 종합 회귀는 [PRD 4단계](../plans/2026-11-17-local-save-refresh-prd.md#4단계--실패복구와-windows-패키지-검증)에 남겨 두었다.
