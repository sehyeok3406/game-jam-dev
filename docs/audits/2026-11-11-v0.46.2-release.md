# v0.46.2 배포 기록

2026-11-11 [v0.46.2 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.46.2)를 게시했다. 태그는 `main`에 푸시한 소스 커밋 `cb510ebe20bd88c238a17316d81ffbc0a88b03b4`를 가리킨다.
