# v0.46.0 배포 기록

2026-11-06 [v0.46.0 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.46.0)를 게시했다. 태그는 소스 커밋 `00a7eac73149d620eec9c81a8490fb1d011792c2`를 가리킨다. [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/42219323865)의 타입·린트·Windows 자동 테스트·Linux 서버 검사가 통과했다.

캔버스 파일 노드의 크기·열림 상태 복원, HTML 재생 유지, 이미지 설명 편집, 연결선 단축키, 전체 캔버스의 기본 크기 적용을 최종 Windows 패키지에서 확인했다. 임시 협업 서버와 두 격리 프로필로 개인 보기 분리와 위치 링크를 확인했다. 로컬 자동 테스트는 1,225개 통과, 1개 건너뜀이다. 첫 Windows CI에서 확인한 휴지통 보존 기간 차이는 만료 시각을 기록한 삭제 시각으로부터 계산하도록 수정했다.

`make --from-package`로 검증한 패키지에서 설치 파일을 생성했다. 패키지 리소스 2,046개의 크기와 SHA-256이 설치용 nupkg 내부와 일치했다. 내장 협업 서버 번들의 SHA-256 `729ba44c86b275fc22f727d8316cb534293c7912e190e9351f184d59e0239464`가 별도 빌드 결과와 같고 번들 실행 검사도 통과했다.
