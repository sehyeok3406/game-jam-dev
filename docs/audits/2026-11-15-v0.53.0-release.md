# v0.53.0 배포 기록

2026-11-15 Windows x64 정식 릴리스를 게시했다. 배포 커밋과 `v0.53.0` 태그는 `c761b8d08980ef7d700cb81a422679803dfaa698`을 가리킨다. 린트, 타입·계약·코어 검사, 아키텍처 검사와 Windows·Linux CI를 통과했다. 로컬 자동 테스트는 1,248개 통과, 선택 검사 1개 건너뜀이며 패키지 런타임 검사 16개를 통과했다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.53.0) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43664537390)

Windows 패키지에서 공유 기능이 중단된 상태로 시작하고, 기존 PC 사본과 격리된 내장·외부 서버 원본을 휴지통으로 옮기거나 복원·영구 삭제하는 흐름을 확인했다. 서버가 오프라인이거나 원본 상태가 바뀌면 기존 데이터가 보존됐다. 모의 AI CLI와 실제 빌더로 로컬 게임을 제작하고 편집·실패 복구·기록 복원·HTML 내보내기·재시작 후 열기를 확인했다. `tegaki@1.1.0`은 외부 네트워크를 차단한 Electron에서 단일 HTML의 내장 글꼴로 한글·영문 필기를 렌더링했다. 내장·별도 서버 번들의 SHA-256이 일치했고 서버 번들 경계·실행 검사를 통과했다.

검증한 패키지에서 `make --from-package`로 설치 파일을 만들었다. nupkg의 리소스 2,046개는 검증한 패키지의 파일 크기와 SHA-256이 모두 일치했다. 공개 자산 세 개는 익명으로 접근할 수 있었으며 GitHub가 기록한 크기와 SHA-256을 로컬 파일과 대조했다.
