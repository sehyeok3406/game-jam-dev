# v0.45.0 배포 기록

2026-11-05 [v0.45.0 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.45.0)를 게시했다. 배포 파일 게시·검증과 자동 업데이트 피드 반영 완료다. 제품 소스·태그는 `4238f72f3ae3f1793ae158d16dbdd86af249b72f`이다. [CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/42021263873)의 타입·린트·Windows 자동 검사·Linux 서버 작업이 모두 통과했다.

별도 작업 트리에 남아 있던 캔버스 성능 1~7단계를 최신 v0.44.1에 통합한 소스를 배포했다. 확대율 변경의 전체 화면 갱신·노드 재조립·JSON 비교를 줄이고 구역별 상세 표시·제한된 준비 큐/캐시·편집/한글 조합/초안 보호와 실행 HTML 수명 보존을 적용했다. HTML 창 설정의 반복 전체 프로젝트 읽기를 줄이고 이동 도구에서 본문 편집으로 진입하는 동작도 차단했다. 최신 위치·문단 링크와 HTML 제작·내보내기를 유지하며 수동 링크 UI는 복원하지 않았다.

통합 때 수행한 타입·core 타입 검사, 아키텍처 10개, 집중 단위 검사 57개와 위치 링크·HTML UI 검사를 재사용했다. 대표 Markdown/혼합 300개 장면은 각각 한 번 측정했다. RAF 간격 P95는 약 16.8ms였고 본문/geometry 쓰기가 없었다. 최종 Windows 패키지의 링크 종료/실행 중 수신·OS 전달·문단/HTML/텍스트·크고 작거나 회전한 대상 이동이 통과했다. 실제 app.asar에 성능 표시와 최신 제작/링크 UI가 포함되고 수동 링크 class가 없음을 확인했다. 전체 장면 행렬이나 장시간 성능 검사를 반복하지 않았으며 최종 소스의 전체 자동 검사는 CI에서 수행했다. [통합 수치와 범위](2026-11-05-canvas-performance-integration.md).

기존에 검증한 v0.45.0 package를 재빌드하지 않고 make --from-package로 설치 파일을 만들었다. 제품 입력 686개가 검증 후보와 같음을 확인했고 package 이후/make 이후 지문도 같다. 표준 입력 지문은 `95bc4ddaef08bde58bb970d67f73c128444cc4c08f91cf0b33288dedcedcdea2`, app.asar SHA-256은 `4635937d5d72ae80412fdda85d1fa6997b9a033fdf16f0876781c436b86625f8`이다. 후보의 별도 지문은 파일별 해시 map, 배포 표준 지문은 경로·크기·해시 배열을 직렬화하므로 전체 지문 문자열은 서로 다르며 동일 파일 입력을 비교했다. 리소스 2046개의 make 전후와 nupkg 내부 크기·SHA-256도 같다.

GitHub 자산 digest·크기를 로컬과 대조하고 세 파일의 인증 없는 공개 다운로드 접근을 확인했다. 공개 RELEASES 원문과 패키지 이름·SHA-1·크기도 일치한다. 기존 게시/검증 경로를 사용해 대용량 파일 전체를 재다운로드하지 않았다. 게시 직후 업데이트 JSON과 RELEASES 피드는 각각 HTTP 200/200이며 정확한 새 설치 파일·패키지 URL과 해시·크기 반영은 확인했다.

모든 PC/장면의 FPS를 보장하지 않는다. 원본 모델의 전체 메모리, 단일 문서의 동기 처리, 다수 실행 HTML의 비용은 남는다. 기존 v0.44.x 서버와 호환되며 저장 형식·권한 정책 변경과 새 아키텍처 예외는 없다. 운영 서버·터널 또는 사용자 앱을 재시작하거나 업데이트 설치를 강제하지 않았다. 관련 없는 비추적 계획/연구 자료는 포함하지 않고 원래 성능 작업 트리를 보존했다. [검증 JSON](2026-11-05-v0.45.0-release-evidence.json), 로컬 결과물/로그는 out/release-v0.45.0에 보존한다. 단계별 시간 측정은 추가하지 않았다.
