# v0.54.3 배포 기록

2026-11-16 Windows x64 정식 릴리스를 게시했다. 배포 커밋과 태그는 `cf7decb829b8b90c36f8d9faa7675659c79e9031`를 가리킨다. 타입·계약·코어·아키텍처, 린트, Windows 자동 테스트, Linux 서버·복구 CI가 통과했다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.54.3) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43878640283)

배포용 Windows 실행 파일에서 Project-PP_gamejam의 격리 사본을 열어 취조 파트 프로토타입의 게임 카드에서 제작 정보 줄이 사라지고 HTML 히스토리에서 원본 및 기준 문서를 확인할 수 있는지 검증했다. 00_CORE 링크로 문서를 열었다. 패키지의 라이트·다크 테마, 카드 크기, 외부 파일 경고, 접기·펼치기와 전체화면 UI 검사도 통과했다. 로컬 자동 테스트는 1,254개 통과, 선택 검사 1개 건너뜀이다.

검증한 패키지에 `make --from-package`를 적용했다. 빌드 전후와 설치 파일 생성 후 추적 소스 1306개의 지문은 `314c9f0ea544b54598f60427370f923332d53b608a0d019987f36edb95204e90`로 일치했다. nupkg 리소스 2046개는 검증한 패키지의 SHA-256과 크기를 유지했다.
