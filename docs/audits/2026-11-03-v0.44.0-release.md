## 소스·결과물 보존

제품 입력 672개 지문은 `6efe966fa59085b8465702ea1c26189a3e6f89fec969da30db6b7234767d2bf4`다. 패키징 전후와 make 이후 지문이 같다. `make --from-package`로 검증한 패키지를 재사용했으며 make 전후 및 nupkg 내부 리소스 2,046개의 크기·SHA-256이 모두 같다. 리소스 지문은 `01d925acca29caf421d496637d53d8b2b4b0c4aa6d8688657e8bec67a5cd912d`, app.asar SHA-256은 `33a83564ed94f9ced709e692fc000dd8824bb27bb6d12f2b31979baf6ee19d79`다.

내장 Node 24.19.0으로 서버 번들의 경계·독립 실행·권한·SSE/WS·재시작·새 합성 Windows 백업 복원·부하 검사를 통과했다. 서버 SHA-256은 `09641ad8763fd4b03541965b13002b13224515233d34a66047a9677625fe7d91`다. 검사 결과 JSON은 배포 기록으로 옮기고 원래 패키지 리소스 바이트가 그대로임을 대조했다. 새 아키텍처 예외나 검사 완화는 없다.

## 남은 범위

문단 링크에는 이를 지원하는 최신 협업 서버와 앱이 필요하다. 별도 운영 서버와 Cloudflare 터널은 교체·재시작하지 않았다. 사용자 설치 앱에 업데이트를 강제로 적용하지 않았으며, 실제 두 PC·특정 메신저·설치/업데이트/제거의 전체 수명은 이번 검증과 구분한다. 원문/외부/AI 편집으로 제거된 문단 앵커, 경로 기반 레거시 파일 개명 등은 구현 안내의 제약을 유지한다.

수치와 공개 검증은 [배포 검증 JSON](2026-11-03-v0.44.0-release-evidence.json), 로컬 결과물·로그는 `out/release-v0.44.0`에 보존한다. 단계별 시간 측정은 추가하지 않았다.
