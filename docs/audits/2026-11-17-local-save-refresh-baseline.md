# 로컬 저장과 화면 갱신 기준선

2026-11-17 · PRD 0단계 완료 · 기준 커밋 `54b656720488f539626dd727a925c926b70c00ea`

## 측정 조건

Windows x64 빌드의 메인·프리로드·렌더러 번들을 격리된 임시 앱에 복사하고 같은 버전의 Electron `44.5.1`로 실행했다. 메인에 IPC와 파일 호출 계측을 붙였다. DevTools에서 타이핑·포인터·단축키 입력을 보내고 화면 DOM의 변화를 기록했다. 기준 `app.asar`의 SHA-256은 `189d4684e1d6e615066dbd0ca920ca4635e38332d992a8cafe0cac93899954a1`이다.

새 로컬 테스트 프로필과 합성 프로젝트로 같은 시나리오를 세 번 실행했다. 프로젝트에는 일반 Markdown 문서 122개, 섹션 파일 1개, HTML 결과 5개가 있다. 그림 캔버스에서는 준비 획 한 개를 저장한 후 약 0.45초 길이의 펜 획을 6개 긋고 마지막 획을 `Ctrl+Z`로 되돌렸다. 외부 편집은 앱 프로세스 밖에서 메모 파일에 한 문단을 추가했다.

- **조회**는 메인에 도착한 목록 호출 횟수다. **파일 읽기**는 메인 프로세스에서 성공한 Node `readFile` 호출로, 동일 파일을 여러 번 읽으면 각각 센다. 아래 읽기 표의 문서·그림·HTML은 프로젝트 원본을 집계한다.
- **원본 저장**은 해당 원본 경로의 교체 성공 횟수다. 초안, 문서 저장 큐, 변경 전후 히스토리, 히스토리 항목 파일의 쓰기는 각각 성공한 `writeFile` 호출을 셌다. 이 카운터는 운영체제 수준의 물리 디스크 I/O와 구분한다.
- **화면 반영 지연**은 입력 명령을 보내기 직전부터 목표 DOM이 처음 확인될 때까지다. 펜은 마우스를 떼는 시점부터 완성된 획이 노드로 나타날 때까지 잰다. **원본 저장 지연**은 같은 시작점부터 원본 경로 교체 성공까지다. 렌더러는 계측 창에서 실행했으므로 시간은 동일 PC에서 비교하는 기준으로 사용한다.
- 준비 동작과 시나리오 사이의 `Ctrl+S`는 관측 구간 밖에 배치했다. 메모 입력은 입력부터 약 1.9초를 관측했고, 펜 6획은 첫 획의 시작부터 마지막 획 반영 이후 0.85초까지 포함했다. 되돌리기와 외부 변경은 화면 반영 뒤 0.75초까지 관측했다.

## 비용이 생긴 경로

1. **메모 저장과 외부 변경.** 전체 갱신 한 번에서 `documents:list`가 Markdown 문서 122개를 읽고 `preview:list`가 HTML 결과를 설명하기 위해 프로젝트를 다시 캡처하면서 Markdown 123개를 더 읽었다. `sections:list`와 `workspace:get`도 각각 1개씩 읽었다. 메모를 저장한 경우 저장 큐 안에서 해당 메모를 추가로 6회 읽었다. 이 흐름에서 이번에 수정한 메모를 제외한 읽기가 모두 245회였다. [화면의 전체 갱신](../../src/ui/workspace/workspace-data.ts) · [HTML 결과 목록](../../src/application/editing/preview-service.ts) · [부분 갱신 분류](../../src/desktop/project-file-effects.ts)
2. **연속 펜 획.** 36회 중 24회는 그림 변경 명령의 스냅샷과 원본 확인에서, 6회는 파일 감시가 자체 저장과 일치하는지 확인할 때, 6회는 화면의 그림 목록 갱신에서 발생했다. 획을 마칠 때마다 원본을 교체하고 직전·직후 그림 파일을 히스토리에 기록했다. [그림 초안과 저장](../../src/ui/drawing/useDrawing.ts) · [로컬 작업의 변경 전후 비교](../../src/application/editing/local-mutation-service.ts) · [히스토리 저장](../../src/project-store.ts)
3. **펜 한 획 되돌리기.** 원본 확인과 저장에서 그림을 2회 읽었다. 화면의 직접 그림 갱신과 변경 알림에 따른 그림 갱신이 각각 1회, 감시기의 자체 저장 대조가 1회였다. 이 경로는 문서·섹션·HTML 전체 목록을 호출하지 않았다. [그림 범위 되돌리기](../../src/application/editing/edit-history-service.ts) · [화면의 되돌리기 처리](../../src/ui/workspace/WorkspaceScreen.tsx)
