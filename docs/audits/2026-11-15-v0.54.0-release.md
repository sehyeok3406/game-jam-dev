# v0.54.0 배포 기록

2026-11-15 Windows x64 정식 릴리스를 게시했다. 배포 커밋과 태그는 `e60cd61d60d51f66ccfd7dd2a77cd73da3cf25d4`를 가리킨다. 타입·계약·코어·아키텍처, 린트, Windows 자동 테스트, Linux 서버·복구 CI가 통과했다. 배포용 실행 파일을 격리된 프로필과 임시 프로젝트에서 확인했다. 선택한 노드에서 Space를 누른 채 드래그하면 캔버스가 이동했고 Enter로 노드가 열렸다. 본문 색 지정·초기화와 읽기·편집 적용을 확인했다. 그리기 도구를 첫 클릭에 선택하고 다시 눌러 종류를 바꿨다. 사용자 지정 키가 하단에 표시되고 실제 동작에 적용됐으며 중복을 거부했다. 저장한 키와 본문 색은 재시작 후 유지됐다. 쌓임 순서는 앞뒤 이동·펼치기·실행 취소·다시 실행 및 재시작에서 확인했다.
