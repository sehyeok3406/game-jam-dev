# v0.53.2 배포 기록

2026-11-15 Windows x64 정식 릴리스를 게시했다. 배포 커밋과 `v0.53.2` 태그는 `61f1f7b3ceb4127e9f7407df6db68d1a249b5cfb`를 가리킨다. 타입·계약·코어·아키텍처 검사, 추적 파일의 린트, GitHub의 Windows·Linux CI가 통과했다. 로컬 자동 테스트는 1,250개 통과, 선택 검사 1개 건너뜀이었다. 내장 서버 번들의 경계·실행 검사도 통과했다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.53.2) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43691983143)

실제 배포용 Windows 패키지에서 `Project-PP_gamejam`의 격리 사본에 있는 `전세혁` 캔버스를 열었다. 텍스트·도형·섹션·게임 UI 프레임을 옮기고 바로 선택 해제해도 전체 HTML 목록 요청은 없었다. 텍스트와 도형은 새 위치와 기존 내용을 보존했다. 파일·도형의 원자적 묶음 명령, Markdown 크기 조절, 칸반 카드 이동은 변경된 상태를 화면과 디스크에 반영했다. 큰 HTML을 펼칠 때 연결 에셋을 준비하는 요청은 75ms였다. 외부에서 편집한 Markdown 본문은 전체 갱신 경로를 통해 화면에 반영됐다.

기존 텍스트·칸반 Windows 패키지 스크립트 두 개는 직전 비교 검사에서 v0.53.1과 수정한 패키지 모두 같은 UI 준비 단계에서 시간 초과가 발생했다. 이번 배포에서는 위 작업을 격리한 프로젝트 사본으로 별도 검증했다.

검증한 패키지에 `make --from-package`를 적용했다. 빌드 전후와 설치 파일 생성 후 추적 소스 1,300개의 지문은 `06b0dbf654f5e6430f786bcb78d0589f11e0e798d8bed771afd1a0e0b4c91aaf`로 일치했다. nupkg의 리소스 2,046개는 검증한 패키지와 SHA-256 및 크기가 모두 일치했다.

| 파일                            |    바이트 | SHA-256                                                            |
| ------------------------------- | --------: | ------------------------------------------------------------------ |
| `Game.Jam-0.53.2.Setup.exe`     | 239620608 | `850b63bf236e5bcd08959257f132ca690c746b04a8acdd0c9d36c5659a5eadb3` |
| `game_canvas-0.53.2-full.nupkg` | 239613654 | `052e0b191ed05d3ac623fa449c18c3d9ee71b48c7dd0b7e8c379859b929ae6e7` |
| `RELEASES`                      |        83 | `086c4f5384ace6dc512965105a75cbf181613053461de368c41911e2ef4da5c4` |

공개된 자산 세 파일 모두 인증 없이 HTTP 206으로 접근했다. GitHub 자산의 SHA-256·크기와 공개 `RELEASES` 원문은 로컬 결과물과 일치했다. `RELEASES`의 패키지 이름, SHA-1 `0D24541ABE2E778A80FCF890AA7DFEC7AB0DC3D5`, 크기 239613654바이트를 확인했다.

게시 직후 v0.53.1 기준 업데이트 JSON은 HTTP 204를 반환했고 Windows Squirrel 피드는 v0.53.1 패키지를 안내했다. 배포 파일 게시·검증 완료, 자동 업데이트 피드 반영 대기 상태였다. 검증 로그는 `out/release-v0.53.2`에 있다.
