# v0.51.0 배포 기록

2026-11-14 Windows x64 정식 릴리스를 게시했다. 공개 태그는 배포 소스 `e64b0706b24e3068e25782e2d3a21ccc9d475017`을 가리킨다. 타입·계약·코어·아키텍처·린트·Windows 자동 테스트·Linux 서버/백업 검사가 통과했다. 로컬 자동 테스트는 1,247개 통과, 선택 검사 1개 건너뜀이다. [GitHub 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.51.0) · [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43572626616)

최종 패키지에서 모의 AI CLI로 실제 빌드와 초기 실행 검사를 거쳤다. 이미지와 CSS 텍스처, MP3 재생과 위치 이동, FBX 애니메이션, MTL 텍스처가 적용된 OBJ, BLEND에서 변환한 GLB, 48,405,256바이트 GLB를 확인했다. 두 게임 버전의 파일 재사용, 노드 삭제, 이전 버전 복원과 앱 재시작을 검증했다.

`make --from-package`로 설치 파일을 만들었다. Windows 패키지 리소스 2,046개의 SHA-256과 크기가 nupkg 내부와 일치한다. 내장 서버와 별도 서버 번들의 SHA-256 `9a875a10185c1a5937e472eec9952e62963b5276c84a7c9e1f69e7356fe43cea`가 일치하고 서버 번들 실행 검사가 통과했다.
