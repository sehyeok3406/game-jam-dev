# v0.48.0 배포 기록

2026-11-12 [v0.48.0 정식 릴리스](https://github.com/sehyeok3406/game-jam-dev/releases/tag/v0.48.0)를 게시했다. 공개 태그는 배포 소스 `c1c8d05d5a68e1e9567a12744f32cf841ce4a536`을 가리킨다. 타입·아키텍처·린트·Windows 자동 테스트·Linux 서버 검사가 통과했다. 로컬 자동 테스트는 1,238개 통과, 선택 검사 1개 건너뜀이다. [GitHub CI](https://github.com/sehyeok3406/game-jam-dev/actions/runs/43200781434)

최종 Windows x64 패키지에서 우클릭 위치에 빈 섹션 생성·실행 취소·다시 실행, MD와 이미지의 클릭 동작, 노드 글씨 크기 설정과 재시작 복원, 캔버스 텍스트의 선택 영역·미니맵·너비 조절, GLB 탐색·반복 재생 중 Follow Camera의 구도 유지를 확인했다. 공동 이미지 리사이즈 회귀는 첫 실행에서 크기 변화를 포착하지 못했고 같은 패키지에서 재실행해 통과했다.

`make --from-package`로 검증한 패키지에서 설치 파일을 만들었다. Windows 패키지 리소스 2,046개의 SHA-256과 크기가 nupkg 내부와 일치한다. 내장 협업 서버와 별도 서버 번들의 SHA-256 `56bf4a11cee4e0868193fab6d6162295c319ae1d3972cbc78225273bbe669bc0`이 일치하고 서버 번들의 실행 검사가 통과했다.
